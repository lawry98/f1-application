# Driver headshot credits

Every file in this directory is a photograph hosted on Wikimedia Commons. The images are
free to reuse, but **not** public domain — most are CC BY or CC BY-SA, which oblige
attribution, and CC BY-SA additionally obliges share-alike on adaptations. This file is
that attribution.

The committed PNGs are downscaled (longest edge 400 px) and transcoded from the Commons
originals by `frontend/scripts/fetch-team-assets.mjs`; under CC that makes them derivative
works, which is why the licence column matters and not just the author column.

Author and licence below are the `Artist` and `LicenseShortName` fields returned by the
Commons API (`action=query&prop=imageinfo&iiprop=extmetadata`) — they are not inferred from
the filename. Re-derive them for any file by opening its source link.
