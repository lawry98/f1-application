# Team logo credits

Every file in this directory is a vector mark hosted on Wikimedia Commons under a
public-domain tag (`PD-textlogo` / `PD-shape`) — the designs fall below the threshold of
originality for copyright, so **no attribution is legally required**. This file exists for
provenance: so the next person can tell an official mark from a fan recreation without
re-doing the sourcing.

**They are still registered trademarks.** Public domain settles copyright, not trademark.
Use is limited to nominative identification of the team — naming and depicting the team
being written about — which is what `/teams` does. Do not treat these as free-to-remix
artwork or as an endorsement by the marque.

Licence and author below are the `LicenseShortName` and `Artist` fields returned by the
Commons API; `Artist` on a public-domain logo names the rights-holding marque, not an
illustrator.

## Not present

`racing-bulls.svg` is absent. No freely licensed vector of the Visa Cash App Racing Bulls
mark exists on Commons — searched by title, by category and by full text. The only SVG that
surfaced was a user-made icon, i.e. a fan recreation, which is worse than nothing.
`TeamLogo` renders its `RAC` monogram fallback instead.

## Marque marks standing in for team lockups

Four files are an authentic public-domain mark of the correct company, but narrower than
the full Formula 1 team lockup, for which no free vector exists:

| File | What it is | What it is missing |
|---|---|---|

| `aston-martin.svg` | the Aston Martin wordmark | the winged badge |

## Sponsor names baked into the artwork

`haas.svg` reads *TGR Haas F1 Team*, `audi.svg` reads *Audi Revolut F1 Team* and
`williams.svg` reads *Atlassian Williams F1 Team*. These are the current official lockups;
where one disagrees with the team name in `data/teams-data.ts`, the data file is the thing
to reconcile, not the asset.
